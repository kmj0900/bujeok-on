## 4. 알려진 한계·메모
- **AI는 수리검을 피한다(2026-11-25).** 예고된 줄 전체를 위험 지도에 시간 구간으로 넣어 기존 폭발 회피 로직을 그대로 쓴다. 줄 밖으로 나갈 칸이 없게 상자·바위에 갇힌 배치는 못 피한다(부적으로 상자를 부수지 않는 한). 브라우저에서 AI 대전으로 직접 본 것은 아직 없다. 일부 단위 테스트(`blank()` 맵 등)만 `hazards: false`로 돌린다.
- **AI 난이도(2026-11-25).** 사용자 테스트에서 AI가 너무 어렵다는 의견이 있어 **쉬움·보통**을 넣었다. 보통은 기존 동작 그대로, 쉬움은 판단 주기 0.5초·안전할 때 가끔 0.3~0.8초 멈춤·상대 공격 점수 20·폭발 회피 여유 0.05초·봉인 탈출 연타 0.22초(8회는 풀고 12회부터 못 풂). 값은 `js/ai.js`의 `AI_LEVELS`. AI끼리 30판 시뮬레이션에서 보통이 쉬움을 12승 7패 11무로 앞선다. 사람과 했을 때의 체감은 사용자 확인 전이다.
- **(난이도 도입 전 메모) AI가 빠르고 공격적이다.** 쉬지 않고 최고 속도로 움직이고 상대를 적극적으로 노려 AI 대전이 30초 안팎에 끝나기도 한다. 난이도(쉬움/보통)는 모든 구현이 끝난 뒤 추가 변경 단계에서 한다.
- 폭포 계곡 위쪽·왼쪽 암벽은 이끼가 있지만 아직 벽돌을 쌓은 느낌이 남아 있다(바위산처럼 자연 암벽으로 바꿀 수 있음, 사용자 요청 시).
- 낙석 돌 7개 단계(120초 이후)가 너무 아프면 6개로 낮춘다(`maps.js` mountain `rockCounts`). 사방이 막힌 칸의 닌자·AI는 낙석·수리검을 피할 수 없다.
- AI는 아이템을 찾아다니지 않는다(지나가다 밟을 때만 줍는다). 상대 움직임 예측·체력/무적 인식도 없다.
- 같은 칸에 두 닌자가 있을 때 아이템은 1P(번호가 빠른 쪽)가 먼저 얻는다(단순화).
- 폭발 중인 칸에서 상자가 부서져 나온 아이템은 그 칸의 폭발이 모두 끝난 뒤 나타난다(그 전에는 줍기·파괴 불가).
- `assets/maps`, `assets/sounds` 폴더는 비어 있다(효과음은 코드 합성, 맵 이미지는 추가 맵 때 사용).
- 참고용으로 받은 AI 생성 이미지(디자인 가이드·아이템 목록·맵 콘셉트)는 분위기·팔레트 참고에만 쓰고 파일로 가져오지 않았다(`AGENTS.md`).
- 개발은 VS Code Live Server에서만 확인했다. `file://`로는 ES Modules가 열리지 않는다.

- **크레이지 아케이드와 같지 않나**: 부적 설치·회피 구조는 참고했다고 인정하고, 차별점(맵마다 다른 위협 수리검·물살·낙석, 체력 4·봉인 연타 탈출 8→12→16, 닌자 테마 아이템 3종, 위험 지도 AI, 직접 만든 도트 그래픽, 랜덤 대칭 맵)을 말한다.
