# 기능 요구사항 및 수용 기준

## P0: 반드시 완성
| ID | 기능 | 수용 기준 |
|---|---|---|
| R01 | 메인/맵/모드 선택 | 시작 후 맵(깊은 숲·폭포 계곡)을 고르고, 로컬 2인·AI 대전 중 선택해 시작 |
| R02 | 기본 맵 | 깊은 숲 15×13 표시, 외곽·고정 장애물·상자 구별 |
| R03 | 로컬 이동 | WASD/방향키 동시 입력, 벽/상자 충돌 정상 |
| R04 | 부적 | Space/Enter 설치, 한도·중복 설치 제한 |
| R05 | 폭발 | 2.5초 후 십자 폭발, 0.4초 유지, 벽/상자 판정 |
| R06 | 연쇄 폭발 | 다른 부적에 닿으면 즉시 유폭, 중복 처리 없음 |
| R07 | 체력·봉인 | 체력 2. 피격 시 체력 -1과 무적 1.5초, 체력 0이 되면 2초간 봉인 후 탈락 |
| R08 | 승패 | 승리/무승부/시간 종료 판정 정확(시간 종료 시 체력 비교 포함) |
| R09 | 재대결 | 부적·상자·타이머·체력·무적·봉인 등 플레이어 상태 완전 초기화 |
| R10 | 기본 AI | 장애물 이동, 폭발 위험 회피, 탈출 가능할 때 부적 설치 |
| R11 | UI | 조작법, 남은 시간, 게임 상태, 결과 표시 |
| R12 | 일시정지 | P/메뉴로 중단, 퓨즈·봉인·타이머 모두 멈춤 |
| R13 | 배포 | Render 공개 URL에서 PC 브라우저 실행 가능 |
| R14 | 안정성 | AI와 한 판 완주, 로컬 2인 한 판 완주, 콘솔 치명 오류 없음 |

## P1: 핵심 완료 후
| ID | 기능 | 수용 기준 |
|---|---|---|
| E01 | 아이템 3종 | 경공술·화약 강화·부적 두루마리, 최대치 적용 (**구현됨**) |
| E02 | 폭포 계곡 맵 | 동일 게임 엔진에서 데이터·이미지 교체로 실행 |
| E03 | 효과음 | 음소거 가능, 저작권 문제 없는 소리 사용 (아이템 획득음만 구현, 코드로 합성) |
| E04 | AI 개선 | 상대 추적·아이템 탐색 등 |
| E05 | 맵 위협 | 모든 맵에 예고가 있는 위협이 주기적으로 발생(깊은 숲: 수리검). 맵마다 위협 종류가 다름. `docs/16_NEXT_PLAN.md` |

## P2: 여유가 충분할 때
- 바위산 맵, 달빛 사원 맵
- 맵 선택 UI(2개 이상 완성 후)
- 캐릭터 이동/승리 애니메이션
- AI 난이도 선택, 브라우저 로컬 전적 저장

## 범위 제외
온라인 멀티플레이, WebSocket 서버, 회원가입, 데이터베이스, 랭킹, 은신/대체술, 승급 도전 스토리 모드. (수리검은 플레이어가 던지는 기술이 아니라 **맵 위협**으로 2026-11-24에 범위에 포함했다.)

## 품질 기준
- 새 기능 추가 전 기존 P0 동작을 재확인한다.
- 조작 입력으로 브라우저가 스크롤되거나 버튼이 의도치 않게 눌리지 않는다.
- 에셋 누락 시 게임 전체가 중단되지 않도록 기본 대체 렌더링을 둔다.
- 발표용 데모는 인터넷 접속 후 URL에서 실제로 실행한다.

## 구현 우선순위와 기능 축소 규칙
- P0는 **출시/발표를 위한 목표**이며, 일정 위험이 생기면 P0 중에서도 `로컬 2인 한 판 완주 → 기본 AI 한 판 완주 → 배포/시연` 순으로 안정성을 우선한다.
- 능력 두루마리는 구현되어 게임에서 획득할 수 있다.
- 추가 맵은 최소 1개가 **테스트까지 완료**된 경우에만 맵 선택 UI를 표시한다.
- 화면 해상도, 조작키, 폭발 타이밍, 결과 판정은 문서 간 동일해야 한다.
