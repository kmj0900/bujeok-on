# 바이브 코딩 개발·검증 기록 템플릿

## 작업 기록
- 날짜 / 단계:
- 목표 기능 및 요구사항 ID:
- AI 도구에 입력한 프롬프트:
- 생성·수정된 파일:
- 직접 검토한 핵심 코드/설계 결정:
- 실행 환경(브라우저/OS):
- 테스트한 항목(테스트 ID):
- 결과(성공/실패/미실행):
- 발견된 버그 및 재현 단계:
- AI 수정 요청과 수정 후 결과:
- Git 커밋 또는 버전:
- 발표용 캡처/영상 파일명:

## 발표용 최소 사례
1. 기능 생성 프롬프트와 실제 동작 결과
2. 오류 재현 → 원인 분석 → 수정 프롬프트 → 재검증
3. 기능 범위 조정(온라인 제외, AI/로컬 선택, 맵 공통화)의 근거
